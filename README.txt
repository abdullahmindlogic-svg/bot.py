INSTALLATION
============

Install the required Python libraries:

pip install pyTelegramBotAPI requests


RUN
===

Run the bot with:

python premium_bot.py


TELEGRAM BOT TOKEN
==================

The bot uses an Environment Variable named:

TELEGRAM_BOT_TOKEN

For cloud hosting, add the following:

Name:
TELEGRAM_BOT_TOKEN

Value:
Your Telegram Bot Token


SECURITY
========

NEVER upload your real Telegram Bot Token to GitHub.

Do not put your real Bot Token directly inside public source code.

Keep your Bot Token private.

If a real Bot Token is accidentally published, revoke it using BotFather and create a new one.


MEMORY
======

The bot supports local SQLite memory.

It can also attempt to save memory to Firebase Firestore using the configured Firebase project.

Firebase Firestore Security Rules must allow the required operation for Firebase saving to work.


SEARCH
======

The bot can process App and Game search requests.

Examples:

CapCut app

Android game

search video editor

download photo editor

GitHub stores the source code.

The actual availability of 24/7 operation depends on the hosting provider and its plan limits.
